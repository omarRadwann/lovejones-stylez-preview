# Love Jones Stylez Preview

Private outreach concept for Love Jones Stylez. Built with Vite, Three.js, and GSAP ScrollTrigger.

## Run

```bash
npm install
npm run dev -- --port 5173
```

Open http://127.0.0.1:5173/

## Build

```bash
npm run build
```

## Notes

- `LOVEJONES_CONTENT_AUDIT.md` contains the rendered content scraped from the live Love Jones pages.
- This preview uses public image URLs from the current Love Jones site for private outreach context.
- Do not publish as an official site without owner approval.
